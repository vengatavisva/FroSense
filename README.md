# FroSense (EcoFrost)

![FroSense Banner](https://via.placeholder.com/1200x400/0ea5e9/ffffff?text=FroSense+-+AI-Powered+Cold+Storage)

> **Smart Cold Storage, Sustainable Future.**

FroSense (EcoFrost) is an AI-powered, solar-driven cold storage management and monitoring application. It is designed to minimize food spoilage, optimize energy use, and empower farmers sustainably through smart predictions, IoT insights, and solar innovation.

## 🌱 Why FroSense?

Traditional cold storage is expensive, energy-hungry, and inaccessible to small farmers. FroSense brings intelligence, efficiency, and sustainability to every farm:

- **Reduce Food Waste:** AI-powered monitoring prevents spoilage before it happens.
- **Energy Efficient:** Solar-powered Peltier cooling optimized by machine learning.
- **Smart Predictions:** Predictive algorithms forecast optimal cooling schedules.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <your-repository-url>
   cd FroSense
   ```

2. Navigate to the app directory:
   ```bash
   cd frosense
   ```

3. Install the dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open your browser and navigate to the provided local URL (typically `http://localhost:5173`).

## 📁 Project Structure

- `frosense/src/pages/` - Main views (Home, Inventory, AIInsights, About)
- `frosense/src/components/` - Reusable UI components (Navbar, Counters, EnergyFlowDiagram)
- `frosense/src/context/` - React Context providers for state management
- `frosense/src/assets/` - Static assets and images
